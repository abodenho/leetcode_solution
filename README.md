# LeetCode Solutions

Hi,

The main goal of this repository is to share solutions to algorithmic problems found on [LeetCode](https://leetcode.com/).

The repository will follow this structure:

```text
Repo
├── Problem 1
│   ├── description.md
│   ├── C++
│   │   └── solution.cpp
│   ├── Python
│   │   └── solution.py
│   ├── Java
│   │   └── Solution.java
│   └── ...
├── Problem 2
│   ├── description.md
│   └── ...
└── ...
```
Each folder in this repository will correspond to a problem. Inside each problem folder, there will be a **description.md** file containing the problem description and a link to the original LeetCode problem.

There will also be one subfolder for each programming language used to solve the problem, such as C++, Python, Java, and others. Each language folder will contain the corresponding implementation of the solution. 

**Note:** I try to use different approaches and logic for each programming language, mainly to avoid rewriting the exact same solution multiple times.
